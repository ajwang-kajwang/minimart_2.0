# Minimart Shopper Monitoring System

This repository contains the source code for the Minimart retail analytics platform, divided into **Edge** (On-Premise) and **Cloud** (Remote) components.

---

## 📂 minimart

**Production Edge System**

- **Role:** Real-time on-premise orchestration and inference.
    
- **Architecture:** Edge AI (Local Processing).
    
- **Hardware:** Raspberry Pi 5 + Hailo-8L NPU.
    
- **Stack:** Python (Backend), Next.js (Local Dashboard).


---

## 📂

**Cloud & Web Infrastructure**

- **Role:** Cloud data aggregation and remote services.
    
- **Architecture:** Server-Client (AWS).
    
- **Components:** AWS Server, Cloud Database, Remote Frontend.
